# Simple Interest Calculator

This project contains a simple interest calculator implemented using a shell script.

## Formula

Simple Interest is calculated using the following formula:

**Simple Interest = (Principal × Rate × Time) / 100**

Where:

* **Principal** = Initial amount of money
* **Rate** = Annual interest rate
* **Time** = Time period in years

## Usage

Run the calculator using:

```bash
./simple-interest.sh
```

The script asks the user to enter the principal amount, annual interest rate, and time period, then calculates and displays the simple interest.
